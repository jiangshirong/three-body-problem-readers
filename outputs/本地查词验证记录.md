# 本地查词验证记录

验证日期：2026-09-05。

## 交付内容

本机阅读器增加 Wiktionary / Kaikki 美式 IPA 子集；中文释义保留 ECDICT，但不再打包其 phonetic 字段。词典子集、署名、逐词来源、口音标签、覆盖报告与缺失表均已落盘。无外部发布、无购买、无实际语音合成请求。

## 自动验证

- 查词与现有服务共 28 项测试通过：US 标签过滤、英式/未标注/北美标签拒绝、大小写边界、原形与变形分离、多读音、覆盖统计、旧在线缓存过滤、手动录音缓存、现有语音缓存/密钥保护等。
- Python 提取测试 3 项通过：美式音频标签不能“传染”旁边的 IPA；原始语法信息保留；正文提词不包含标签、属性及 HTML 实体名称。
- 网页构建通过。
- 项目另有 2 项早期“starter loading skeleton”测试失败：它们仍要求初始空白模板的标记及结构，与当前已经使用阅读器 iframe 的项目不符。本次没有修改这些无关断言，也不声称整个项目所有测试通过。

## 实际浏览器验证

用独立测试浏览器打开正在运行的本机阅读器，没有更改用户浏览器的阅读进度或设置。

- 断网后点击 contemptuously：立即显示中文释义和 /kənˈtɛmp.t͡ʃu.əs.li/；一次点击到文字可见测得约 54 毫秒（单次观测，不是性能保证）。
- had：明确显示暂无本词美式音标，原形 have 的音标另列，并写明“不是 had 的读音”。
- whirred：显示自身 /wɝd/，不是 whir/whirr 的原形读音。
- read：保留 /ɹid/ 与 /ɹɛd/，后者标明过去式／过去分词。
- record：保留两种名词/形容词读音及动词读音 /ɹɪˈkɔɹd/。
- the：明确显示“暂无美式音标”；浏览器内记录的查词 fetch 调用数为 0。
- 手动录音按钮：注入旧格式缓存响应（包含伪造音标、US 与 UK 音频）后，只显示 US 录音按钮，不显示或改写本地音标；未自动播放。
- 手动录音查询失败后，本地释义/IPA 保持不变，查询按钮恢复可用。
- 合成发音按钮：请求被测试层拦截，验证其选择阿里云 Flash / John、只发送选中单词与已保存提示词；没有实际调用付费语音服务。
- 完全离线的新浏览器环境直接打开 file:// 下的单文件网页，选章节并点击难词，释义和音标正常。
- 检查 1440×960 和 800×600 窗口：查词面板及按钮可见；窄窗口面板左右边界 352–782，纵向 72–507，内部无横向溢出。长内容允许面板内滚动。

## 生效方式

刷新网页即可使用新本地查词；正在运行的服务仍为版本 7，新接口版本 8 已写入文件并用隔离测试验证。双击“重启阅读器.cmd”后加载新接口。新网页同时兼容旧接口，并在前端再次过滤，因此重启前旧缓存也无法把在线 IPA 带回界面。没有停止用户正在运行的阅读器服务。

## 数据边界

本地文件中没有任何靠 CMUdict、拼写规则或模型生成的 IPA。部分高频词只有未标口音的记录，因此严格筛选后的覆盖率有限，见“美式音标覆盖报告.md”。有“US/General-American + 其他口音”共享标签的同一音标可保留，其他口音标签仅作为原始溯源信息，不作为候选英式音标展示。
