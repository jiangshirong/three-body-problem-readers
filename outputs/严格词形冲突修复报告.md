## 修改的词形

- axes：词形 ax → ax；词族 axes → ax。例句中为斧头的复数，应归入 ax 词族，而非轴。
- bore：词形 bear → bore；词族 bore → bore。书中 bear 过去式与 bore 原形各一次；平局保留原组
- bored：词形 bear → bore；词族 bore → bore。例句中 bored 表示感到无聊，属于 bore 使厌烦的派生形容词，保留 bore 族。
- boring：词形 bear → bore；词族 bore → bore。例句中 boring 表示令人无聊的，属于 bore 使厌烦的派生形容词，保留 bore 族。
- evening：词形 even → evening；词族 evening → evening。名词“傍晚”，与 even 不同词，应归 evening 词族。
- evenings：词形 even → evening；词族 evening → evening。evening 的复数，strictId 应为 evening。
- ground：词形 grind → ground；词族 ground → ground。本书例句中绝大多数为名词“地面/场地”，应归入 ground 而非 grind 的过去式。
- grounds：词形 grind → ground；词族 ground → ground。ground 的复数，指场地或庭院，与 ground 同族。
- ids：词形 id → id；词族 ids → id。id 的复数形式，应归入同一 strictId 和 familyId。
- lie：词形 lay → lie；词族 lie → lie。本书例句中既有说谎义，也有躺下义，均属 lie 词族；现有 familyId 为 lie。
- lies：词形 lay → lie；词族 lie → lie。lie 的第三人称单数或复数名词；例句中多为谎言义，也有位于义，均属 lie 词族。
- lying：词形 lay → lie；词族 lie → lie。lie 的现在分词；例句中既有躺卧义，也有说谎义，均属 lie 词族。
- leaf：词形 leaf → leaf；词族 leave → leaf。树叶义，单数名词，归入 leaf 词族
- leave：词形 leaf → leave；词族 leave → leave。离开义动词，例句均为离开/留下，归入 leave 词族
- leaves：词形 leaf → leaf；词族 leave → leaf。树叶义复数，例句中 rotting leaves 等指树叶，归入 leaf 词族
- leaving：词形 leaf → leave；词族 leave → leave。leave 的现在分词，例句均为离开义，归入 leave 词族
- left：词形 leaf → leave；词族 left → leave。书中主要用作 leave 的过去式，也有方向义；静态归属按主要用法
- number：词形 numb → number；词族 number → number。名词'数字/号码'，应归入number基础词
- numbering：词形 numb → number；词族 number → number。number的动名词/现在分词，归入number
- numbers：词形 numb → number；词族 number → number。number的复数/第三人称单数，归入number
- rose：词形 rise → rise；词族 rose → rise。在本书例句中均为rise的过去式，表示升起，而非玫瑰；根据同形异义按主要用途决定，归入rise。
- ups：词形 up → ups；词族 ups → ups。书中为 ups and downs 的名词；与 up 不是同一严格词形
- wound：词形 wind → wound；词族 wound → wound。本书例句均为名词'伤口'义，应归入wound词族，而非wind的过去式。
- wounded：词形 wind → wound；词族 wound → wound。形容词/过去分词'受伤的'，派生自wound（伤口）义。
- wounding：词形 wind → wound；词族 wound → wound。动名词'伤害'，派生自wound（伤口）义。
- wounds：词形 wind → wound；词族 wound → wound。名词复数'伤口'，与wound同词形。
