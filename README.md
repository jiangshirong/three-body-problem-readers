# Three Body Problem - readers

《三体》英语阅读器：一个面向英文原著阅读、查词和词汇学习的本地优先工具。

## 功能

- 按章节阅读《三体》英文原文，并保存阅读位置。
- 点击单词查看本地音标、当前语境中的短释义、词形和词族信息。
- 标记生僻词、学习词和熟词新用。
- 框选词组进行释义或标记为学习词组；按住 `Ctrl` 可以追加不连续的词汇。
- 使用 `Q`、`E`、`W` 快捷键执行释义、生僻词和学习词操作。
- 支持字号、主题、朗读声音和播放速度设置。
- 可选接入阿里云朗读、DeepSeek 解释和本机朗读模型；不配置在线服务也可以阅读已有内容。

## 快速开始

### 环境要求

- Windows
- Node.js

### 启动

双击：

```text
启动英语阅读.cmd
```

然后访问：

```text
http://127.0.0.1:8766
```

请通过本机地址打开阅读器，不要直接双击 `outputs/three-body-reader.html`。本地服务负责提供学习标记、阅读进度、密钥保护和其他本机功能。

## 目录说明

```text
outputs/      阅读器页面、词典、音标和统计资料
服务/         本地阅读服务及数据处理脚本
启动英语阅读.cmd
package.json
```

## 本地数据与在线服务

- 阅读进度、学习标记、密钥和本地朗读缓存保存在本机服务管理的数据目录中，不依赖浏览器 `localStorage` 作为主要存储。
- 阿里云朗读和 DeepSeek 解释属于可选功能，只有在用户配置相应密钥并主动使用时才会请求在线服务。
- 不配置在线服务也可以阅读已有内容、查阅本地资料和使用已有的学习记录。

## 数据来源与许可

词典、音标和相关统计资料来自不同的数据处理流程。具体来源、许可和校准报告见 `outputs/` 中的说明文件，尤其是：

- `outputs/ECDICT-LICENSE.txt`
- `outputs/PRONUNCIATION-LICENSE.txt`
- 美式音标校准和覆盖范围报告

使用或再分发其中的数据时，请同时遵守对应数据源的许可条款。

## 项目状态

这是一个个人使用中的本地阅读工具。词典覆盖、音标、句中释义和 AI 返回内容仍可能需要人工核对。
